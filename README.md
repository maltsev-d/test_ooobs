# Orders Sync Service

Забирает сырые заявки с внешнего API, нормализует телефоны, дедуплицирует, отдаёт чистый JSON.

## Эндпоинт

`GET /` — возвращает список клиентов и статистику.

## Локальный запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Деплой (Render)

- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`

## Как устроено

- Stateless, БД нет, секретов нет. Каждый запрос фетчит свежие данные с источника.
- Идемпотентность бесплатная: нет состояния — нет дублей.
- Нормализация телефонов: убираем всё кроме цифр, принимаем 10 или 11-значные, приводим к `+7XXXXXXXXXX`. Остальное
  дропаем.
- Дедупликация по телефону: оставляем запись с максимальным `amount`; при равных — более позднюю по `created_at`.
